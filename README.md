# ⚡ Kotha-Hisaab (Room Rent Calculator)

A lightweight, beautifully designed Progressive Web App (PWA) tailored for tenants and landlords to track monthly room rent and split utility bills effortlessly.

---

### 📝 Project Description
This is a simply designed Room Rent calculator which is named in the Nepali Language:
* 🏠 **Room** : Kotha
* 🧮 **Rent** : Hisaab

Although it can be created via different programming languages, this app is built purely in **HTML** (paired with vanilla JavaScript and Tailwind CSS). This structural simplicity provides the merit for fast, easy, and user-convenient operation. 

---

### 🚀 Merits of this App

1. **Zero Cost for Lifetime Hosting** Since the app runs completely on the client side without needing an active backend server or remote database management, it can be hosted 100% free forever via platforms like GitHub Pages.

2. **Complete Data Privacy for Users (Local Storage)** No tenant or financial data ever leaves the user's phone. All payment histories, calculations, and inputs are saved securely inside the device's native browser `localStorage`.

3. **Maximum Loading Speeds and Offline Support** With no server roundtrips required to fetch data, calculations update instantly. Thanks to PWA capability, the application works seamlessly even if the user is completely offline or has a weak internet connection.

4. **Simple Maintenance & Web-to-App Flexibility** All features reside in a straightforward asset layout. This makes modifications painless and allows the web platform to be added directly to an Android/iOS home screen or wrapped into a standalone mobile package without a rewrite.

---

### 📱 How to Use / Install on Mobile

1. Open your smartphone browser and navigate to the live site:  
   👉 **`https://sangharsa-adk.github.io/Kotha-Hisaab/`**
2. Tap the **three vertical dots (Menu)** in Google Chrome.
3. Select **"Install app"** or **"Add to Home screen"**.
4. Launch **Kotha-Hisaab** straight from your mobile application drawer in full-screen standalone mode!
